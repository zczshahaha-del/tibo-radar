# 补齐最新回复上下文，修正来源新鲜度与跨帖判断

最新普通动态没有回复关系时，原实现只把正文交给 AI；现在按原帖 ID 查回复关系，
再补齐父帖和引用帖，并与重置相关列表共享缓存。查不到时明确标记未知或缺失。

跨帖重复日期需要检查是否为同一事件及其反证，取消必然提高重置卡概率的规则。
各来源分别检查缺失、缓存及过期状态，并交给 AI；面板沿用橙色提示，悬停刷新
时间可查看具体问题，其他来源的更新时间不再掩盖 Tibo 来源异常。

关联本地 Issue 13。改动未涉及面板尺寸和展开方式、刷新间隔、模型切换与通知逻辑。

# 这次修改做了什么

- 撤下 DeepSeek / 千问直接生成的精确百分比。
- AI 只判断无信号、弱信号、强信号或明确预告，并保留可核对证据。
- 增加独立概率质量门；历史回放未达标时显示“暂无可靠概率”。
- 通知改为响应强信号、明确预告和确认事件。
- 旧百分比缓存升级后不再读取。

## 相关 Issue

Issue 5：不再显示 AI 自报的未校准概率。

## 为什么这样做

AI 自报的 30% 没有经过历史回放校准，“证据很弱”也不能让这个数字变得
可信。产品只有在数字能通过过去结果检验时才应该显示概率。

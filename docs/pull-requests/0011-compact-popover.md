# 这次修改做了什么

- 第一版折叠方案被拒绝后，重新实现用户确认的极简卡片。
- 把 24/48 小时综合概率并列放在同一层级。
- 只在默认面板保留“重置额度”和“重置卡”的 24 小时分类概率。
- 删除行动建议、条件时段、概率范围和默认解释段落。
- 展开区只保留最多三条主要依据和可用的原始来源链接。
- 顶部改为“上次刷新 HH:mm”；依据区使用 0.2 秒淡入淡出和箭头旋转，不再
  让文字产生位移动画，并遵循 macOS“减少动态效果”设置。
- 设置页改为与预测页一致的 344 点紧凑布局，统一绿色强调色并删除大块留白、
  灰色刷新按钮和重复“完成”操作。
- 删除设置页顶部的钥匙串说明和中间的模型能力说明，进一步压缩信息。
- 模型服务改为全宽双选项控件，与模型名称和 API Key 输入框左右对齐。
- 预测页默认状态和设置页使用相同的 344×350 点外框，切换时不再缩放窗口；
  设置页删除重复标题以容纳紧凑布局。

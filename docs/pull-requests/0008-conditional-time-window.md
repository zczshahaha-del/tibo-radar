# 这次修改做了什么

- 主预测从只显示区间改为显示 AI 中心估计，并在下面保留可能范围。
- 全局重置、普发卡和故障补发同时显示中心估计与范围。
- 时间字段从 `likely_window` 改为 `conditional_window`。
- 界面固定写“若发生，较可能在”，明确时间是在事件发生这个前提下的相对偏好。
- 没有明显集中时段时显示“暂无集中时段”。

## 相关 Issue

Issue 8：概率与发生时段必须表达同一件事。

## 为什么这样做

较低的 24/48 小时概率与具体的条件时段可以在数学上同时成立，但旧界面省略
了“假设事件发生”这个前提，让具体时间看起来像确定日程。上一轮只显示范围，
也不便于用户快速判断。因此新版同时给出中心估计、范围和带条件的时间偏好。

# 决策 3：规则预测核心未被接受，改用 AI 判断

- 日期：2026-09-10
- 状态：方向已确认，接入方式待选
- 相关：Issue 2，待建 Issue 3

## 背景

原生菜单栏候选版能够联网拉取公开 JSON，但最终概率来自本地规则加减分。
用户明确指出这种方式不能理解 Tibo 的语气、回复上下文、玩笑、暗示、事后
描述和社区传言，因此不能作为产品的核心预测能力。

## 决定

不接受当前规则预测核心，也不把 `feature/2-native-menubar` 按现状合并到
`main`。菜单栏外壳可以在后续分支复用，但正式预测必须由 AI 完成：

1. AI 对每条新增证据做语义分类和范围判断。
2. AI 汇总近期证据、历史节奏和反面信号，输出结构化概率。
3. 使用历史事件回测、校准模型输出，并明确显示不确定性。
4. 传统规则只做确定性的工程工作，不再冒充语义预测。

## 待决定

AI 接入可以走独立 OpenAI API，也可以走 Codex app-server 的 ChatGPT 登录
流程。两者在费用、独立性、部署复杂度和额度来源上不同，选定后再创建
Issue 3 和实现分支。

# 用普通话解释预测时间和可靠性

## 问题现象

AI 预测面板右侧显示“高发时段”和“置信度”，实际结果出现
“若发生，最可能落在此……”的截断文字以及单独一个“低”。用户无法判断
它们分别在说什么，也看不到为什么可靠性低。

## 环境

- Tibo Radar v0.3.0 候选版
- macOS 菜单栏弹出面板
- DeepSeek AI 快照

## 真正原因

- “高发时段”“置信度”是分析术语，没有解释成用户要做的判断。
- 时间字段只允许显示一行，AI 返回长句时被省略号截断。
- `confidenceNote` 已保存在快照中，但界面没有展示，所以“低”没有原因。
- 提示词没有强制时间字段使用短格式，模型可能返回一整句话。

## 这次要做什么

- 把“高发时段”改成“最可能什么时候”。
- 没有可靠时间时统一显示“暂时算不出”，有时间时允许两行完整显示。
- 把“置信度”改成“这个判断靠谱吗”，显示“比较靠谱 / 仅供参考 / 证据很弱”。
- 在主概率下面直接显示一条简短说明，解释可靠性为什么高或低。
- 收紧 AI 提示词，要求时间只返回简短北京时间或“暂无可靠时间”。
- 增加文字转换和视觉快照测试。

## 怎样判断完成

- [ ] 面板不再出现“高发时段”“置信度”等未解释术语。
- [ ] 时间内容不会因为单行限制而只剩省略号。
- [ ] 可靠性高低有可见原因，不需要用户猜。
- [ ] 旧缓存中的长句也能显示成可理解的短文字。
- [ ] 自动测试、视觉检查和 Release 构建通过。
- [ ] 用户检查新版界面后决定是否接受。

## 风险

- 只改显示和 AI 输出要求，不改变概率计算、API Key 或缓存格式。
- 旧快照继续兼容，不需要清理用户缓存。

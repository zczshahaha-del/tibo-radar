# 实现 Tibo Radar 第一版

## 为什么要做

用户需要在 Tibo 或 OpenAI 可能发放 Codex 福利重置前收到有根据的概率提醒，
而不是普通额度周期提醒或到账后的被动检查。

## 这次要做什么

- 采集公开重置信号、历史和状态事件。
- 计算分类型概率并显示证据。
- 提供本地网页、命令行和 macOS 阈值通知。
- 添加缓存、去重和离线测试。

## 这次不做什么

- 不兑换重置卡，不接入个人账户写操作，不发布公网版本。

## 怎样判断完成

- [ ] `snapshot` 能输出当前概率和理由。
- [ ] `serve` 能打开本地可视化页面。
- [ ] `watch` 只在跨阈值或事件确认时通知一次。
- [ ] 网络错误可以回退到缓存。
- [ ] 自动测试通过。

## 风险和不确定问题

- 数据或存档：有，只保存公开快照和通知去重状态。
- 登录、权限或安全：无，不读取登录凭据。
- 接口：有，第三方公开 API 结构可能变化。
- 配置和发布：有，第一版只提供本机运行方式。
- 外部服务：有，依赖公开重置雷达和 OpenAI Status。

# 默认面板只保留决策需要的信息

## 问题

当前菜单栏面板同时展示 AI 解释、历史基准和两条证据详情，同一判断被重复说明，
用户打开后很难快速找到真正影响用量安排的信息。

## 修改范围

- 默认保留 24/48 小时概率、两类福利概率、使用建议、条件时段和一句关键原因。
- 历史基准、证据详情和来源链接放入“查看详细依据”，默认收起。
- 收起详情时缩短菜单栏面板，展开或进入设置时再恢复完整高度。
- 不修改 AI 提示词、预测概率、数据源、通知或两小时巡检。

## 怎样确认已经解决

- [x] 默认面板不再同时出现三段重复解释。
- [x] 不展开详情也能看到概率、建议、时间和关键原因。
- [x] 用户需要核对时仍能展开历史基准、证据和来源链接。
- [x] Swift 自动测试、视觉快照和 Release 构建通过。
- [ ] 用户检查候选 App 后决定是否合并。
